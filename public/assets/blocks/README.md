# Block Background Assets

This directory contains the background imagery for the Value Proposition Bento Grid blocks on the homepage:

- `block-discover.jpg`: Block 1 - Discover & Understand (Aspect Ratio ~4:3 or 16:9, Recommended: 1200x800)
- `block-strategize.jpg`: Block 2 - Strategize & Propose (Aspect Ratio ~1:1 or 4:3, Recommended: 800x800)
- `block-build.jpg`: Block 3 - Build/Implement (Aspect Ratio ~1:1 or 4:3, Recommended: 800x800)
- `block-launch.jpg`: Block 4 - Launch & Support (Aspect Ratio ~4:3 or 16:9, Recommended: 1200x800)

To replace any block background, simply upload or overwrite the corresponding file name in this folder.
